🔒 Fix DOM-based XSS vulnerability in agora.js

🎯 **What:** The vulnerability fixed
Fixed a DOM-based Cross-Site Scripting (XSS) vulnerability in `agora.js` where user-controlled input was being directly injected into the DOM via `.innerHTML` without sanitization.

⚠️ **Risk:** The potential impact if left unfixed
Malicious users could inject arbitrary JavaScript code into input fields. When this data was rendered via `.innerHTML`, the injected scripts would execute in the context of the application, potentially leading to unauthorized actions or compromising the user's session.

🛡️ **Solution:** How the fix addresses the vulnerability
Introduced a robust `escapeHTML` helper function that sanitizes input by escaping critical HTML characters (`&`, `<`, `>`, `'`, `"`). This function is now used to wrap all user-controlled data (like `timestamp`, `concept`, `green`, `red`, and `blue`) before assigning them to `.innerHTML`, effectively neutralizing any script tags or attributes and mitigating the XSS risks.
